    Access Requests

    The Autonomy Park is located at the UF Energy Park, called the UF Solar Park on Apple and Google maps: - Google Maps Link - Apple Maps Link

    Mandatory Training

    All access requests will be DENIED if you do not complete the online training first. Reach out to Dr. Kamalapurkar; a safety manager will add you to the Canvas.

    Access to the Autonomy Park

    Link to Form

    Fill it out and submit TWO forms as follows.

    First submission

    This request gives you access to both sheds next to the park where all equipment is stored.

    • Request Type: Room and/or Building Access
    • Access Type: Building Only
    • Building(s): Autonomy Park
    • Rooms: 1644 & 1645
    • Supervisor: Rushikesh Kamalapurkar (Put your advisor if you're a MAE graduate student)
    • Details/Justification: Autonomy Park access for robotics research

    Second submission

    This request is needed for bathroom access in the Student Design Center at the Solar Park.

    • Request Type: Room and/or Building Access
    • Access Type: Building Only
    • Building(s): Solar Park
    • Rooms: 0980
    • Supervisor: Rushikesh Kamalapurkar (Put your advisor if you're a MAE graduate student)
    • Details/Justification: Bathroom access for Autonomy Park

    Gate code

    Only those who have completed the training will receive an email or a Canvas announcement with the gate code to UF Energy Park. This is different from the keycode access to the bathroom and sheds above.

    Get Access to Dr. Kamalapurkar's On-Campus Motion Capture Lab

    This request is needed for students working under Dr. Kamalapurkar and needing access to an indoor motion capture lab for robotics.

    • Request Type: Room and/or Building Access
    • Access Type: Room Only
    • Building(s): MAE-A
    • Rooms: 313
    • Supervisor: Rushikesh Kamalapurkar
    • Details/Justification: Lab access for robotics research
