The IP addresses are not published on the wiki. Using a robot needs a username and password as well, and we do not publish those.

!!! note "Two Separate Networks"
    The Autonomy Park and the Indoor Lab each have their own network, and both use the 192.168.1.x range. The same address can mean a different device in each.
