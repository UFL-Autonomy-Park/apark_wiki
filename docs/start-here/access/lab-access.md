    All access requests will be **DENIED** if you do not first read the Lab Rules, watch the safety video, and pass the quiz.

[Go to Safety](../safety.md){ .md-button }

## When Will I Get Access?

Expect one to two weeks. Access moves in two stages. Dr. Kamalapurkar has to approve your request first. Then UF MAE Facilities has to input your door codes.

If it has been more than two weeks, email [facilities@mae.ufl.edu](mailto:facilities@mae.ufl.edu). Every request goes through Dr. Kamalapurkar, and he has to know you, so a lab manager may have forgotten to relay your request to him or to remind him. If that is not the problem, the request is waiting on Facilities. It is usually the former.

## Access to the Autonomy Park

[Link to Form](https://my.mae.ufl.edu/ccb/facilities/requests/changes.asp?id=new){ .md-button }

Fill out and submit **two** forms, as follows.

### First Submission

This request gives you access to both sheds next to the park where all equipment is stored.

| Field | Enter |
|---|---|
| Request Type | Room and/or Building Access |
| Access Type | Building Only |
| Building(s) | Autonomy Park |
| Rooms | 1644 & 1645 |
| Supervisor | Rushikesh Kamalapurkar |
| Details/Justification | Autonomy Park access for robotics research |

### Second Submission

This request is needed for bathroom access in the Student Design Center at the Solar Park.

| Field | Enter |
|---|---|
| Request Type | Room and/or Building Access |
| Access Type | Building Only |
| Building(s) | Solar Park |
| Rooms | 0980 |
| Supervisor | Rushikesh Kamalapurkar |
| Details/Justification | Bathroom access for Autonomy Park |

### Gate Code

The Autonomy Park is behind a gated enclosure. Only those who have **completed the training** will receive an **email or a Canvas announcement** with the gate code to UF Energy Park. This is **different** from the keycode access to the bathroom and sheds above.
