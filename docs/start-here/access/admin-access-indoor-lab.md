Two of the Indoor Lab computers, `MAE-WD-DTG7FZ3` and `MAE-BPLKHL2`, are managed by UFIT. Admin access to them is requested with a UF Engineering IT ticket. See [IP Reservations](../../software/ip-reservations.md) for the computers.

!!! warning "Talk to Dr. Kamalapurkar First"
    All these requests go through Rushikesh Kamalapurkar, because the computers' tags belong to his lab. Make sure you have spoken to him before you submit the ticket. See [Contacts](../contacts.md).

## Steps

1. Open the ticket form:

    [Enter a Ticket](https://www.it.eng.ufl.edu/support/enter-a-ticket/){ .md-button }

2. Fill in the form as follows, then click **Submit**.

| Field | Enter |
|---|---|
| Identification: Name, Gatorlink, UF Email, Phone | Your own details |
| Identification: Location | `MAE-A 313` |
| Support Team | MAE |
| Request Type | User |
| Summary | Admin Access Request |
| Description | I'd like admin access to `MAE-WD-DTG7FZ3` and `MAE-BPLKHL2` for robotics research. |

## After You Submit

Expect up to two weeks. The request moves in two stages: Dr. Kamalapurkar has to approve it, then UF Engineering IT completes the ticket. You should receive an email confirming that your ticket was completed.
