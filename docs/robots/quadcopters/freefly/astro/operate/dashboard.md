  How to open the settings panel that each Astro serves, from a web browser.
---

Each Astro serves a settings panel (dashboard). Type the Astro's local IP address into a web browser to open it. This works while the Astro is connected to Wi-Fi, which is set up on its remote. The addresses are on [IP Reservations](../../../../../software/ip-reservations.md).

Over USB-C, open `https://10.41.1.1/` in a web browser instead. See [USB-C Port](../usb-c-port.md).
