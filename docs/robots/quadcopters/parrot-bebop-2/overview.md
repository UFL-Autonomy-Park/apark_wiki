## Set Up

1. Check the [Known Issues](known-issues.md), and pick a Bebop marked ready to fly.
2. Grab a battery, and insert it into the Bebop. Check the [Batteries](batteries.md) page first.
3. Double press the button on the rear until the LED turns on. It chirps and whirrs to show it is starting up.
4. Make sure the propellers are tight, using the propeller tool below.
5. Check that each propeller is on the correct motor. Nothing stops you from putting the wrong propellers on the wrong motors, so watch the video on the [Autonomy](autonomy.md) page for details.
6. Inspect the arms for bending.
7. Use hot glue to attach a motion capture marker, or pick a Bebop that already has one.
