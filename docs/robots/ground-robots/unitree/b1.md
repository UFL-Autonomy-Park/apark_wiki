## Dog Startup Instructions

The commands run on your Linux computer, and then on the dog's Jetson.

<iframe width="560" height="315" src="https://www.youtube.com/embed/YFhxZseHqzQ?si=ApI6ApXRVbPpgOCy" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe>

1. SSH into the dog's Jetson from your computer. The username and IP address are labeled on the side of the dog. Enter the password when asked.

    ```
    ssh <username>@<dog-ip-address>
    ```

2. Run `screen`, so that the terminal is not killed if you disconnect. Press the space bar a few times until the text goes away.

    ```
    screen
    ```

3. On the dog's Jetson, start the Docker container.

    ```
    ./openDockerDogsHumble.sh
    ```

4. In the container, go to the `localFiles` folder and run the ROS 2 startup script.

    ```
    cd /home
    ./runUnitreeMinimalStartup.sh
    ```

When you are finished, press Ctrl+C to kill ROS. Then leave the container, kill the screen session with Ctrl+A then K, and confirm with Y. Then leave the SSH session.

```
exit
```
