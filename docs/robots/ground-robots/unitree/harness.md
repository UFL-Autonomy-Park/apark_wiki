![A Unitree robot dog hanging by a strap from the crossbar of an aluminum frame, its feet just off the floor.](../../../images/ground-robots/unitree-harness.jpg){ width="40%" }

*The harness frame holding a robot dog (from the Unitree Harness Manual).*

The harness can be used with the Go1 or the B1 to test a low-level motor controller (for example, RL) on the dog in a safe way before having it work on its own.

No one has ever done this. The metal needed to assemble the harness is in the Indoor Lab.
